## US-01 สมัครสมาชิกและเข้าสู่ระบบ
ในฐานะผู้ใช้ใหม่ ฉันต้องการสมัครสมาชิกและเข้าสู่ระบบ เพื่อเห็นเฉพาะโครงการที่ฉันอยู่
Acceptance Criteria
- Given ยังไม่มีบัญชีที่ใช้อีเมลนี้ When กรอกชื่อ อีเมล และรหัสผ่านแล้วกดสมัคร Then ระบบสร้างบัญชีและพาไปหน้าโครงการของฉัน
- Given มีบัญชีแล้ว When กรอกรหัสผ่านผิด Then ระบบไม่ให้เข้าและแสดงข้อความว่าอีเมลหรือรหัสผ่านไม่ถูกต้อง

## US-02 สร้างโครงการและเพิ่มสมาชิก
ในฐานะหัวหน้าทีม ฉันต้องการสร้างโครงการและเพิ่มสมาชิกเข้าโครงการ เพื่อรวมงานของทีมไว้ที่เดียว
Acceptance Criteria
- Given หัวหน้าทีมเข้าสู่ระบบแล้ว When สร้างโครงการชื่อ "งานรับน้อง" Then โครงการนี้แสดงในรายการโครงการของหัวหน้าทีม
- Given โครงการ "งานรับน้อง" มีอยู่แล้ว When เพิ่มสมหญิงด้วยอีเมลที่สมัครไว้ Then สมหญิงเห็นโครงการนี้เมื่อเข้าสู่ระบบ

## US-03 เพิ่มงานในโครงการ
ในฐานะหัวหน้าทีม ฉันต้องการเพิ่มงานพร้อมชื่องานและกำหนดส่ง เพื่อไม่ต้องจดงานในแชต
Acceptance Criteria
- Given อยู่ในโครงการ "งานรับน้อง" When เพิ่มงาน "ออกแบบหน้าแรก" กำหนดส่ง 5 ธ.ค. Then งานใหม่แสดงในรายการด้วยสถานะ todo
- Given อยู่ในหน้าเพิ่มงาน When กดบันทึกโดยไม่กรอกชื่องาน Then ระบบไม่บันทึกและบอกว่าต้องกรอกชื่องาน

## US-04 มอบหมายงานให้สมาชิก
ในฐานะหัวหน้าทีม ฉันต้องการมอบหมายงานให้สมาชิก เพื่อให้ทุกคนรู้ว่าใครรับผิดชอบงานไหน
Acceptance Criteria
- Given หัวหน้าทีมเปิดงาน "ออกแบบหน้าแรก" ที่ยังไม่มีผู้รับผิดชอบ When เลือกสมหญิงแล้วกดบันทึก Then งานแสดงผู้รับผิดชอบเป็นสมหญิง
- Given สมหญิงไม่ได้เป็นสมาชิกของโครงการ When หัวหน้าทีมเปิดรายการผู้รับผิดชอบ Then ไม่มีชื่อสมหญิงให้เลือก
- Given ผู้ใช้เป็นสมาชิกธรรมดา When เปิดงาน Then ไม่เห็นปุ่มมอบหมายงาน

## US-05 เปลี่ยนสถานะงาน
ในฐานะสมาชิก ฉันต้องการเปลี่ยนสถานะงานของฉัน เพื่อให้หัวหน้าทีมเห็นความคืบหน้าโดยไม่ต้องถาม
Acceptance Criteria
- Given งานของฉันมีสถานะ todo When กดเลื่อนสถานะ Then สถานะเป็น doing
- Given งานของฉันมีสถานะ doing When กดเลื่อนสถานะ Then สถานะเป็น done
- Given งานมีสถานะ done When พยายามเปลี่ยนกลับเป็น todo Then ระบบไม่เปลี่ยนสถานะและแสดงข้อความว่าเปลี่ยนย้อนกลับไม่ได้
