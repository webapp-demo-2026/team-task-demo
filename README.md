# ระบบจัดการงานของทีม (team-task-demo)

## ปัญหาที่โครงงานนี้แก้
ทีมกิจกรรมของคณะแจกงานกันในแชตกลุ่ม ข้อความเรื่องงานปนกับเรื่องอื่น สมาชิกไม่รู้ว่าใครรับงานไหนไปแล้ว และหัวหน้าทีมต้องไล่ถามความคืบหน้าทีละคน

## ผู้ใช้หลัก
| บทบาท | ทำอะไรกับระบบ |
|---|---|
| สมาชิก | ดูงานของตัวเอง เปลี่ยนสถานะงาน รับการแจ้งเตือน |
| หัวหน้าทีม (ผู้ดูแล) | สร้างโครงการ เพิ่มสมาชิก เพิ่มงาน มอบหมายงาน ดูภาพรวมของทีม |

## Product Goal
ทีมเล็กติดตามงานและได้รับแจ้งเตือนได้ในที่เดียว

## สมาชิกและบทบาท
| ชื่อ (ชื่อเล่น) | GitHub | บทบาทใน Scrum |
|---|---|---|
| สมหญิง | – | Product Owner |
| มานะ | – | Scrum Master |
| สมชาย | – | Developer |
| ชูใจ | – | Developer |

## เอกสารของโครงงาน (โฟลเดอร์ docs)
| ไฟล์ | เนื้อหา |
|---|---|
| `docs/user-stories.md` | User Stories (US-xx) และ Acceptance Criteria |
| `docs/persona.md` | Persona และบันทึกสัมภาษณ์ (รหัสนิรนาม P1–P3) |
| `docs/requirements.md` | Functional (FR-xx) และ Non-functional Requirements (NFR-xx) |
| `docs/use-cases.md` | คำอธิบาย Use Case (UC-xx) |
| `docs/usability-test.md` | แผนทดสอบ สถานการณ์งาน (T-xx) และผลทดสอบ |
| `docs/contributions.md` | ชิ้นงานและเจ้าของ |

## กติกาเรื่องข้อมูล
- ข้อมูลในระบบใช้ข้อมูลสมมติเท่านั้น
- ผู้ให้สัมภาษณ์และผู้ทดสอบใช้รหัส P1, P2, P3 ห้ามใส่ชื่อจริง เบอร์โทร อีเมล ภาพ เสียง หรือคลิปของผู้ให้ข้อมูลใน Repository
